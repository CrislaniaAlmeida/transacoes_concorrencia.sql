# Evidências dos testes

Vou organizar aqui os prints dos experimentos realizados no MySQL Workbench.

Nos testes com concorrência, os registros devem mostrar as duas conexões:

- Sessão A
- Sessão B

Também serão adicionadas evidências dos testes de bloqueio, níveis de isolamento e deadlock.

Os prints serão incluídos depois da execução real dos comandos.
